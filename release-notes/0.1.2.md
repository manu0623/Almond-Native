Arcoon can now hand Almond a game you haven't built yet: launching it from Arcoon starts the build on your device, and once it's done the game opens straight from Arcoon.

.cia and .cxi dumps are recognised alongside .3ds, and a dump that can't be built (encrypted, cut short, or an update or DLC instead of a game) now tells you why.

Quitting a game you started from Arcoon takes you back to Arcoon instead of Almond's own list.

Pressing Home while a game is running hands the bottom screen back to your launcher. Before, the game's bottom screen stayed on top of it.

Builds check there's enough free space before copying a game in, so a full device can't leave a half-copied dump behind.
